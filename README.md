# 绿色氢能供应链补贴模型研究资料

这是围绕绿色氢能供应链成本、碳排放和补贴机制的研究资料归档，适合阅读研究设计、了解实验流程，或准备整理与复现资料的同学和研究者。

项目指南把研究重点放在碳排放惩罚系数 λ、绿色度奖励系数 β 和成本分担比例 α，以及不同运输距离和生产数量下的方案比较。这里保留的是研究指南和归档入口，参数最优值与效果需要结合可复核的模型、数据和结果判断。
