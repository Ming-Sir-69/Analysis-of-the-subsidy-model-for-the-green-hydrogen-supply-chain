# 绿氢供应链补贴模型

围绕绿氢供应链成本、碳排放与补贴机制的研究资料归档。
指南记录碳排放惩罚系数 λ、绿色度奖励系数 β、成本分担比例 α，以及运输距离和生产数量的比较思路。

## 获取与阅读

1. 先读指南，梳理各阶段的输入、输出与假设。
2. 下载 RAR，以支持该格式的工具解压到独立目录。
3. 将实际文件与两份说明对照，再核对 MATLAB 版本、工具箱、数据来源和运行顺序。

克隆或下载仓库 ZIP 只取得文档与 RAR，不会自动展开工程。
