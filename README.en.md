# Green Hydrogen Subsidy Model

A research archive on green-hydrogen supply-chain cost, carbon emissions and subsidy mechanisms.
The guide records carbon-penalty coefficient λ, greenness-reward coefficient β, cost-sharing ratio α, and comparisons across transport distances and production quantities.

## Three files, three roles

| File | Purpose |
| --- | --- |
| [Project guide](绿色氢能供应链优化项目指南.md) | Research goals, parameter definitions and experiment plan |
| [Directory description](文件树结构.md) | Original engineering layout and script organization |
| [氢能实验分析3.0.rar](氢能实验分析3.0.rar) | Engineering archive |

## Obtain and read the materials

1. Read the guide to identify stage inputs, outputs and assumptions.
2. Download the RAR and extract it into a separate directory with a compatible tool.
3. Compare actual files with both documents, then establish MATLAB version, toolboxes, data sources and execution order.

Cloning or downloading the repository ZIP retrieves documents and the RAR; it does not extract the engineering project.
The guide's `.m`, CSV and MAT paths are not expanded as individual files in the current Git tree.

## Check before reproduction

- Some stage, directory and script names differ between the documents; use the actual archive files.
- Archive contents and script completeness have not been verified individually, so no definitive startup command is established.
- Optimal parameters, method effects and conclusions require reproducible models, data and results.

When adding reproduction notes, specify dependencies, relative paths, parameters and references, and separate plans from actual results.
